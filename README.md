# TI-Evrima-Map | The Isle Evrima — Gateway Interactive Map

Интерактивная карта Gateway для The Isle: Evrima. Метки объектов, зоны, пресеты, палитра цветов, поиск игрока по координатам и встроенная проверка обновлений.

## Возможности
- Интерактивная карта с зумом и панорамированием
- Пользовательские метки объектов и зоны (с сохранением)
- Пресеты (сохранение/загрузка в `presets/presets.json`)
- Своя палитра цветов (`custom-colors.json`)
- Поиск игрока по координатам, траектория движения
- Слои: миграция, патруль, убежища
- **Проверка обновлений**: при запуске приложение сверяет свою версию с последним GitHub Release. При наличии новой версии сверху экрана появляется уведомление с кнопкой «Скачать и установить» (живёт 10 секунд либо до закрытия крестиком). Ручная проверка — кнопка ↻ рядом с кнопкой логов (правый нижний угол).
