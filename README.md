# TI-Evrima-Map | The Isle Evrima — Gateway Interactive Map

Интерактивная карта Gateway для The Isle: Evrima. Метки объектов, зоны, пресеты, палитра цветов, поиск игрока по координатам и встроенная проверка обновлений.

## Скачать
[Скачать последний релиз](https://github.com/MrGood727/TI-Evrima-Map/releases/latest)

## Возможности

- __Интерактивная карта__ с зумом и панорамированием
- __Пользовательские метки__ объектов и зоны (с сохранением)
- __Пресеты__: каждый пресет хранится в отдельном файле в `presets/` — список пресетов, загрузка в один клик, переименование, удаление
- __Палитра цветов__ для меток и зон (`custom-colors.json`)
- __Поиск игрока__ по координатам, линия и азимут до курсора, траектория движения
- __Слои карты__: миграция, патруль, убежища (ясли), солёные камни, питьевая вода
- __Переключение языка RU / EN__ — выбор языка запоминается
- __Автообновление__: при запуске приложение проверяет наличие новой версии через `latest.yml` (без лимитов API) и при необходимости предлагает скачать и установить; ручная проверка доступна кнопкой в нижнем правом углу
